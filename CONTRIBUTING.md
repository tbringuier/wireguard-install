# Contributing

This repository does not accept contributions.

It is a personal fork of [angristan/wireguard-install](https://github.com/angristan/wireguard-install)
maintained for one purpose: routing additional public IP addresses to WireGuard clients, as
described in [this tutorial](https://blog.folf.fr/wireguard/). It is not meant to improve the
upstream project, and changes made here are not proposed back.

- Pull requests are closed automatically.
- Issues, discussions and the wiki are disabled.
- Generic WireGuard installer improvements belong upstream: https://github.com/angristan/wireguard-install

You are welcome to fork it under the terms of the MIT licence.
